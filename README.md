# X Heart Animation

Source React Native/Expo gốc nằm ở `src/components/x-heart-animation/`.
Hai bản native độc lập đã được chuyển sang các thư mục riêng:

| Nền tảng | Thư mục | Cách mở |
| --- | --- | --- |
| iOS — Swift | [ios-swift](ios-swift/README.md) | Mở `ios-swift/XHeartAnimation.xcodeproj` trong Xcode |
| Android — Kotlin | [android-kotlin](android-kotlin/README.md) | Mở thư mục `android-kotlin` trong Android Studio |

Chọn máy ảo tương ứng rồi nhấn Run. Cả hai demo đều có nền đen, nút tim ở
giữa màn hình; chạm để thích/bỏ thích. Hai project không cần Expo, Metro,
React Native hoặc thư viện animation ngoài.

Chi tiết đối chiếu source và [video trên X](https://x.com/ngocdevv/status/1982572513445204344)
nằm trong [ghi chú đối chiếu](docs/native-parity.md).

Đã chạy hai bản native trên máy ảo. Kết quả và video nằm trong
[báo cáo QA](docs/qa/README.md).
